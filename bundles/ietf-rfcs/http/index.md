# Concepts

* [RFC 2616: Hypertext Transfer Protocol -- HTTP/1.1 (Obsoleted)](rfc2616.md) - The classic 1999 HTTP/1.1 specification, later obsoleted by the RFC 7230–7235 series and consolidated into RFC 9110 and RFC 9112.
* [RFC 9000: QUIC: A UDP-Based Multiplexed and Secure Transport](rfc9000.md) - Defines the core QUIC transport protocol providing stream multiplexing, low-latency connection establishment, and integrated TLS 1.3 security over UDP.
* [RFC 9110: HTTP Semantics](rfc9110.md) - Defines abstract HTTP protocol semantics (methods, status codes, headers, content negotiation, and connection management) independent of wire version.
* [RFC 9111: HTTP Caching](rfc9111.md) - Defines HTTP caches and the associated header fields that control cache behavior and indicate cacheable response messages (Cache-Control, Age, ETag, Vary).
* [RFC 9113: HTTP/2](rfc9113.md) - Specifies multiplexed binary framing and header compression (HPACK) for HTTP semantics over TCP and TLS 1.3.
* [RFC 9114: HTTP/3](rfc9114.md) - Mapping of HTTP semantics over the QUIC transport protocol (RFC 9000), eliminating head-of-line blocking at the transport layer.
* [RFC 9457: Problem Details for HTTP APIs](rfc9457.md) - Defines a standard JSON and XML problem-detail document (application/problem+json) to carry machine-readable error details in HTTP responses.
