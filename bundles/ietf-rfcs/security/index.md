# Concepts

* [RFC 5246: The Transport Layer Security (TLS) Protocol Version 1.2 (Obsoleted)](rfc5246.md) - Specified TLS 1.2; formally obsoleted by RFC 8446 (TLS 1.3) in August 2018.
* [RFC 8446: The Transport Layer Security (TLS) Protocol Version 1.3](rfc8446.md) - Specifies TLS 1.3 with mandatory forward secrecy, 1-RTT handshakes, encrypted handshake messages, and removal of legacy AEAD-unsafe ciphers.
