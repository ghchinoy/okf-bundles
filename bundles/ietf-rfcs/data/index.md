# Concepts

* [RFC 3986: Uniform Resource Identifier (URI): Generic Syntax (STD 66)](rfc3986.md) - Defines the generic syntax of URIs (scheme, authority, path, query, fragment) and relative reference resolution.
* [RFC 8259: The JavaScript Object Notation (JSON) Data Interchange Format (STD 90)](rfc8259.md) - Defines the canonical JSON syntax, requiring UTF-8 encoding for interoperable network exchange.
* [RFC 9562: Universally Unique IDentifiers (UUIDs)](rfc9562.md) - Updates RFC 4122 and introduces time-ordered UUIDv6, UUIDv7 (Unix Epoch time + random), and custom UUIDv8 formats for database indexing.
