# Concepts

* [Draft: The OAuth 2.1 Authorization Framework](draft-ietf-oauth-v2-1.md) - Consolidates OAuth 2.0 (RFC 6749), Bearer Tokens (RFC 6750), PKCE (RFC 7636), and Security Best Current Practice, removing the insecure Implicit and ROPC grants.
* [RFC 6749: The OAuth 2.0 Authorization Framework](rfc6749.md) - Enables a third-party application to obtain limited access to an HTTP service on behalf of a resource owner or on its own behalf.
* [RFC 6750: The OAuth 2.0 Authorization Framework: Bearer Token Usage](rfc6750.md) - Specifies how to use bearer tokens in HTTP requests to access OAuth 2.0 protected resources over TLS.
* [RFC 7519: JSON Web Token (JWT)](rfc7519.md) - Compact, URL-safe means of representing claims to be transferred between two parties, signed with JWS or encrypted with JWE.
* [RFC 7636: Proof Key for Code Exchange by OAuth Public Clients (PKCE)](rfc7636.md) - Mitigates the authorization code interception attack in OAuth 2.0 using dynamically generated code_verifier and code_challenge secrets.
