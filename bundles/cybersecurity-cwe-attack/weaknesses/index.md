# Concepts

* [CWE-22: Path Traversal](cwe-22.md) - Improper limitation of a pathname to a restricted directory (dot-dot-slash) allows access to files and directories outside the intended root.
* [CWE-287: Improper Authentication](cwe-287.md) - When an actor claims to have a given identity, the software does not prove or insufficiently proves that the claim is correct.
* [CWE-502: Deserialization of Untrusted Data](cwe-502.md) - The application deserializes untrusted data without sufficiently verifying that the resulting data will be valid and safe.
* [CWE-78: OS Command Injection](cwe-78.md) - Improper neutralization of special elements used in an OS command allows arbitrary command execution on the host operating system.
* [CWE-79: Cross-site Scripting (XSS)](cwe-79.md) - Improper neutralization of input during web page generation allows attackers to inject client-side scripts into web pages viewed by other users.
* [CWE-89: SQL Injection (SQLi)](cwe-89.md) - Improper neutralization of special elements used in an SQL command allows attackers to modify or execute arbitrary database queries.
* [CWE-918: Server-Side Request Forgery (SSRF)](cwe-918.md) - The web server receives a URL or similar request from an upstream component and retrieves the contents without ensuring the destination is allowed.
